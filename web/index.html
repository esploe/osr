            Opens paused on the miss moment. Diamonds = taps at the exact cursor spot (green on the note, red + leader line if off), labelled with timing offset. Cyan trail = recent cursor path (white where a key was held); white dot = playhead. Approach rings shrink onto notes like in-game. Hit Play to watch the run-in, or scrub. Scroll to zoom (or the +/−/⤢ buttons), drag to pan. Timing strip below = 300/100/50 windows (green/yellow/orange) with a tick per tap.

    • no tap never pressed a key near the note
      • 
                
    • aim off tapped in time, cursor wasn't on the note
      • 
                
    • early / late on the note, tapped out of window
      • 
                
    • both off wrong place and wrong time

    •  dashed ring = judgment radius
      • 
                
    •  tap that landed on the note

    •  tap that missed (line to the note)
      • 
                
    •  cursor path (white = key held)
      • 
                
    •  playhead during playback
      • 
              
    
            
    
            
    
              
    Timing strip
    
              
      
                
    •    = 300 / 100 / 50 windows
